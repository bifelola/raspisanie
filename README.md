# Расписание МосОМК (Мытищинский филиал)

Автоматически скачивает PDF с расписанием с
https://mocomk.ru/student/raspisaniye/mitish_raspisanie/, распознаёт сканы
(выравнивает наклон, находит сетку таблицы, читает ячейки OCR) и показывает
расписание по выбранной группе. Все недели сохраняются в архиве — даже когда
колледж убирает старый PDF с сайта.

```
scraper/   распознавание PDF (Python: PyMuPDF + OpenCV + EasyOCR)
site/      сайт (статический, работает офлайн, можно «установить» на телефон)
site/data/ архив: index.json + weeks/<понедельник>/<группа>.json + сканы колонок
android/   приложение Android (Kotlin, Jetpack Compose)
```

## Как это работает

1. GitHub Actions (`.github/workflows/update.yml`) каждые 2 часа запускает
   `scraper/update.py`. Скрипт смотрит страницу колледжа и распознаёт только
   новые или изменённые PDF (сравнивает хэш файла).
2. Результат коммитится в `site/data` (это и есть архив) и публикуется на
   GitHub Pages.
3. Сайт и приложение читают эти JSON. Приложение дополнительно хранит все
   открытые недели у себя и раз в 4 часа проверяет обновления (уведомление,
   если вышла новая неделя или расписание поменялось).

## Запуск у себя на компьютере

```bash
py -m pip install -r scraper/requirements.txt
```

```bash
py scraper/update.py
```

```bash
py -m http.server 8000 -d site
```

Затем открыть http://localhost:8000.

Разобрать конкретный PDF вручную:

```bash
py scraper/update.py --pdf file.pdf --start 2026-11-09 --end 2026-11-14
```

## Публикация (GitHub)

1. Создать репозиторий на GitHub и загрузить туда эту папку.
2. Settings → Pages → Source: **GitHub Actions**.
3. Actions → «Обновить расписание» → Run workflow. Сайт появится по адресу
   `https://<логин>.github.io/<репозиторий>/`.
4. Actions → «Собрать Android-приложение» → Run workflow → скачать APK из
   Artifacts и установить на телефон. Адрес сайта подставляется в приложение
   автоматически; поменять его можно в меню ⋮ → «Адрес сервера».

Если сайт колледжа не открывается с серверов GitHub (бывает с российскими
сайтами), запускайте `scraper/update.py` на своём компьютере и отправляйте
изменения в репозиторий — остальное работает так же.
