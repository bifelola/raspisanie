# Telegram-канал с обновлениями и донаты

## 1. Канал (на втором аккаунте)
1. Telegram → карандаш → **Новый канал** → название, например «Расписание МосОМК — обновления», аватарка, описание.
2. Тип: **Публичный**, ссылка, например `t.me/raspisanie_mosomk` (имя придумайте своё).

## 2. Бот, который будет писать посты
1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → имя и ник бота (ник заканчивается на `bot`).
2. BotFather пришлёт **токен** вида `123456:ABC...` — это пароль бота, никому его не показывайте.
3. В канале: **Управление каналом → Администраторы → Добавить** → найдите бота → оставьте право «Публикация сообщений».

## 3. Секреты в GitHub
github.com/bifelola/raspisanie → **Settings → Secrets and variables → Actions → New repository secret**:

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_ID` | `@ник_канала` (с собакой) |

Готово: после каждой новой версии приложения в канал придёт пост «🚀 Вышла версия …» со списком изменений
и кнопками «Скачать APK» и «Веб-версия». Список изменений берётся из описаний коммитов.

**Проверить или написать свой пост:** Actions → «Пост в Telegram» → Run workflow.
Пустое поле — повторить пост о последней версии; свой текст — опубликовать его (например, приветствие).

## 4. Ссылки на сайте
В файле `site/links.js` впишите:
- `DONATE_URL` — ваша страница DonationAlerts: `https://www.donationalerts.com/r/ВАШ_НИК`
  (донаты → «Страница для донатов» в личном кабинете DonationAlerts);
- `TELEGRAM_URL` — `https://t.me/ник_канала`.

Пока ссылка пустая — кнопка на сайте не показывается.
