# Подключение Firebase: вход, комментарии, админка

Без этих шагов приложение работает как раньше: без входа и без комментариев.

1. Откройте https://console.firebase.google.com и войдите своим Google-аккаунтом.
   Нажмите «Создать проект» (Create project), назовите его `raspisanie`. Google Analytics можно выключить.

2. На странице проекта нажмите значок Android («Добавить приложение»):
   - Package name: `ru.mocomk.raspisanie`
   - Debug signing certificate SHA-1: `8C:B3:1A:CD:E7:76:CC:42:F4:CC:53:A1:3B:3F:2C:7E:9A:A7:E2:A3`
   - Нажмите «Зарегистрировать», файл пока не скачивайте, дальше «Далее» до конца.
   - Затем: ⚙ «Настройки проекта» → внизу ваше приложение → «Добавить отпечаток» (Add fingerprint) →
     `CD:4B:6E:78:FF:C5:AD:A9:F0:51:F2:BB:8E:68:D3:B7:C7:CD:1B:FF:C8:15:E1:09:BE:EE:5A:BB:39:36:25:27`

3. Слева «Authentication» → «Начать» (Get started) → вкладка «Sign-in method»:
   - включите «Электронная почта/пароль» (Email/Password);
   - включите «Google», выберите свою почту поддержки и сохраните.

4. Слева «Firestore Database» → «Создать базу данных»:
   - расположение: `eur3 (europe-west)`;
   - режим: «рабочий» (production).
   - Откройте вкладку «Правила» (Rules), удалите всё и вставьте содержимое файла `firebase/firestore.rules`.
     Почта владельца там уже вписана. Нажмите «Опубликовать».

5. ⚙ «Настройки проекта» → ваше Android-приложение → скачайте `google-services.json`
   (скачивайте после шага 3, иначе вход через Google не заработает).
   Положите файл в папку `CODECC/android/app/`.

После этого Claude укажет почту владельца в сборке, отправит изменения на GitHub, и GitHub Actions соберёт новый APK.
